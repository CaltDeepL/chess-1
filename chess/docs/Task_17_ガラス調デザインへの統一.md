# task-17 ガラス調(グラスモルフィズム)デザインへの統一

## ゴールと完了条件
- 全画面を統一したデザインシステムに揃える
- 完了条件: ホーム/ログイン/新規登録/ロビー/対局の全画面が同一のトーンで表示されること

## デザイン方針
| 要素 | 値 |
|---|---|
| 背景 | `#0a0e16`(深い夜色) |
| アクセント1 | `#7dd3fc`(アイスブルー、白駒側) |
| アクセント2 | `#8b7ec8`(スモークバイオレット、黒駒側) |
| パネル | `rgba(255,255,255,0.05)` + `backdrop-filter: blur` |
| 見出し | Fraunces / 本文 Inter / 等幅 JetBrains Mono |

- サイン要素として、盤のマス目パターンを背景にごく薄く沈めた市松模様として使用(ガラス盤を通して見える光というモチーフ)

## 設計判断の根拠
- **当初の「木製チェスクラブ」風配色から全面刷新**: 盤面をガラス調にした時点で、木目・真鍮・フェルトという配色は世界観が合わなくなった。**部分的に足すのではなく、方向性が変わったら全面的に揃え直す**判断
- **CSS変数(`:root`)で一元管理**: 色・フォント・角丸をすべて変数化し、画面ごとに直値を書かない。後の調整が1箇所で済む
- **`HomePage.tsx` を新規追加**: `/` にランディングがなく、未認証ユーザーの入口が `/login` 直行だった。アプリの顔となる画面を用意した

## 実装したファイル
- `src/styles/global.css`: CSS変数、共通コンポーネント(ボタン/入力/パネル)、各画面のスタイル
- `src/pages/HomePage.tsx`: 新規
- `src/App.tsx`: `/` ルートを追加

## つまずいた点と教訓
- 既存のJSXで使っていたクラス名(`auth-page` / `lobby-header` / `game-status-bar` 等)にそのまま対応させたため、コンポーネント側の変更は不要だった
- **教訓**: 実装段階で**仮のクラス名でも意味のある名前を付けておく**と、後からスタイルを当てるときにJSXを触らずに済む。task-10〜16 で「CSSは後回し」としつつクラス名だけは付けていたのが効いた
- `prefers-reduced-motion` とフォーカスリング(`:focus-visible`)は最初から入れた

## 次タスクへの引き継ぎ
- 盤面自体のガラス調化(駒・枠)は別途 `glass-board.css` と駒コンポーネントで対応する(task-18)
- Google Fontsは `@import` で読み込んでいる。本番デプロイ時はパフォーマンスのため `index.html` の `<link>` へ移すのが望ましい
